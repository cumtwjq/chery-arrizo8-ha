# 首次抓取车况请求，以后更新 App 凭证

`获取车况请求.cmd` 只抓取已验证的只读车况请求，不要求在电脑输入奇瑞账号密码，也不需要预装 Python。它不会把 Token、VIN、车辆位置或完整请求打印出来。请求用当前 Windows 用户的 DPAPI 加密保存在 `%LOCALAPPDATA%\Arrizo8HA\capture.dpapi`。成功后自动把新请求复制到剪贴板，供你手动粘贴进 HA。

新版集成另可填写 **App 刷新凭证**。填写后 HA 会自动换取新的车况令牌，并保留你首次导入的完整签名请求。签名若被服务器拒绝，才需要重新抓车况。只填车况请求的旧方式仍可用。

## 首次获取完整已签名车况请求

1. 让电脑和 iPhone 使用之前能正常抓车况的网络。若沿用「iPhone USB 热点 → 电脑 → Windows 移动热点 → iPhone」方案，确保两端都可上网。
2. 双击 `获取车况请求.cmd`，保持黑色窗口打开。它会列出电脑 IPv4 地址；iPhone 所连电脑热点通常是 `192.168.137.1`，请以本机实际地址为准。
3. 在 iPhone 当前 Wi‑Fi 的「配置代理」选「手动」，服务器填电脑在该网络的 IPv4 地址、端口填 `8080`、认证关闭。用 Safari 打开 `http://mitm.it`，应显示 mitmproxy 证书页面。若以前安装的 mitmproxy 证书仍受信任，无需再次安装。
4. 在 iPhone「奇瑞汽车」App 打开艾瑞泽8车况页并刷新。电脑窗口显示「已抓到成功的只读车况请求」后，会自动复制到剪贴板，同时显示令牌到期时间，以及令牌是否与上次相同。
5. 打开家里的 HA：「设置 → 设备与服务 → 奇瑞汽车车况（实验版）→ 配置」，将剪贴板内容直接粘贴到「新的完整车况请求 JSON」并提交。首次添加集成时填入「完整已签名车况请求 JSON」。**不要把内容发到聊天、网盘或公开位置。**
6. 把 iPhone 当前 Wi‑Fi 的代理改回「关闭」，再复制一段普通文字覆盖电脑剪贴板。

如果尚未填写 App 刷新凭证，电脑窗口提示「令牌未变化」且到期时间也没延长，说明 App 当次刷新仍用了原令牌。请先在 App 内自行完成重新登录，再按上述步骤刷新和抓取；不要把相同请求当成已续期。

如果 `mitm.it` 不是证书页面，先检查 iPhone 代理地址和电脑 8080 端口。若已是证书页面但 15 分钟内没有抓到车况请求，检查 App 是否实际刷新、蜂窝数据是否绕开 Wi‑Fi、以及 App 是否仍正常显示车况。Windows 防火墙若询问是否允许代理访问，请只在你信任的私有网络中使用。

抓取窗口结束后会至少停留 10 秒，之后仍需按任意键才会关闭。若提示「端口 8080 已被占用」，先关闭上次遗留的抓取窗口或 mitmdump，再重试。若显示「抓取已加密保存，但复制到剪贴板失败」，双击 `复制HA车况请求.cmd` 重试复制，不必再次抓包。只有看到「已复制车况请求到剪贴板」才去 HA 粘贴。

## 以后用账号密码更新 App 刷新凭证

双击 `账号密码获取App凭证（实验）.cmd`。首次运行时，工具会从[奇瑞官方 App 下载页](https://app.chery.cn/)指向的地址把 APK 下载为**当前解压目录的 `chery-prod.apk`**；下次直接使用同目录文件，无需再次下载。公开压缩包本身不包含 APK。随后在本机输入手机号和密码；工具读取 APK 中的登录加密参数，并为这台电脑创建一个本地设备标识。它不会保存或打印密码。成功后，App 刷新凭证会经 Windows DPAPI 加密保存，并复制到剪贴板。在 HA 原集成「配置」页**只填 App 刷新凭证一项**即可，原有车况签名请求会保留。

该账号在 iPhone 上可能被顶下线；手机重新登录后，请确认 HA 仍能读车况。通用工具的设备标识生成方式还没有其他车主的在线验证，登录失败时不会复制旧凭证，可改用 iPhone 抓包取得 App 刷新凭证。若登录成功但剪贴板被其他程序占用，可双击 `复制App刷新凭证.cmd`，无需再次登录。只有车况签名以后被服务器拒绝时，才需要再次运行 `获取车况请求.cmd`。

压缩包附带的 `mitmdump.exe` 来自 [mitmproxy](https://mitmproxy.org/)，`python/` 是 [Python 官方 Windows 嵌入式发行包](https://www.python.org/downloads/release/python-3147/)。两者都直接在本机运行，使用当前 Windows 用户的既有 mitmproxy 证书目录；压缩包里没有私钥。
