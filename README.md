# 奇瑞艾瑞泽8 Home Assistant 车况集成

将国内版「奇瑞汽车」App 中的艾瑞泽8车况接入 Home Assistant。当前已在 **2022 款艾瑞泽8雅**上验证车况读取，并提供需由车主手动导入请求的实验性寻车和车锁控制。

## 下载与安装

从 [Releases](https://github.com/cumtwjq/chery-arrizo8-ha/releases/latest) 下载：

- `chery_arrizo8-experimental.zip`：Home Assistant 集成安装包。
- `arrizo8-local-capture.zip`：Windows 本地抓取工具，内置 Python 和 mitmproxy，电脑无需另装 Python。

按照[安装说明](INSTALL.md)把集成目录上传到 HA。首次配置需要用[本地抓取工具](local_tool/本地抓取说明.md)从自己的「奇瑞汽车」App 获取一份已签名的只读车况请求，并粘贴到 HA 配置页。以后可在集成的「配置」中更新这份请求。

## 可查看的车况

总里程、平均油耗、剩余续航、剩余油量、车辆位置、车锁、车门、车窗、天窗、后备厢、机盖、发动机、空调状态、左右空调温度及胎压。具体实体以车辆接口实际返回的字段为准。位置按高德 GCJ‑02 坐标校准；[仪表板示例](DASHBOARD.md)使用 HA 自带卡片。

设备页最前面显示**车辆上报时间**、**登录凭证到期时间**和 **HA 上次成功读取时间**，方便判断车况是否过时。HA 约每 30 分钟读取一次；凭证声明到期前 48 小时会在「修复」中提醒，服务器明确拒绝凭证时会启动重新认证流程。

## 实验性车辆控制

可按[本地抓取说明](local_tool/本地抓取说明.md)抓取「寻车闪灯」「车门解锁」「车门上锁」请求。首次启用时，运行 `复制HA全部请求.cmd`，在**原集成的配置页粘贴一次**即可。导入后显示寻车按钮和**车锁控制开关**（打开＝上锁，关闭＝解锁）。开关状态读取车辆回报；每次操作前会刷新车况，命令只发送一次且不会自动重试。寻车按钮的成功仅表示服务器接受命令，无法从 HA 证明车辆实际闪灯。

更新车况请求时，集成会把新令牌同步到已保存的控制请求；旧签名能否在新令牌下继续使用尚未验证。如服务器拒绝控制命令，需要重新抓取相应操作。控制请求只保存在你的本机与 HA 中，**不要分享给他人**。

## 当前限制

- 不支持手机号密码登录、短信登录或自动续期。凭证失效后仍需重新抓取并导入车况请求。
- 启动、空调等控制尚未接入。车主已对照验证常用状态，已确认的车窗通风、完全开启和天窗翘起仍显示细分名称。其他有效数字状态码默认显示为开启（车锁为已解锁、发动机为运行）；这是显示规则，并非所有代码都已实测。缺失或非数字值仍显示为未知。
- HA 主机需要能够访问 `cloudrivechery.mychery.com:443`。车辆上报时间取自服务端车况，可能早于 HA 读取时间。

抓取工具在车主电脑上用 Windows DPAPI 加密保存请求；手动导入后，HA 也会在本机配置中保存该请求。仓库和下载包不包含车主的令牌、VIN、位置或抓包数据。请勿公开分享导出的请求 JSON。
